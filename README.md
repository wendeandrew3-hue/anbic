# ANBIC Insurance Agency website

Four-page marketing site for ANBIC Insurance Agency, Nairobi. "Touching lives with style."

- `index.html` — home (hero, services, why ANBIC, goals)
- `about.html` — story, ANBIC's goals, team
- `quote.html` — free quote form
- `contact.html` — contact details and message form

Static site: no build step. Deploy the repo root. Blue + yellow palette taken from the
agency's own logo. Light and dark themes with a header toggle (saved per visitor).
